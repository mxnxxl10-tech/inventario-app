📋 REQUISITOS PREVIOS
================================================================================
✓ Windows 10/11 (64-bit)
✓ Conexión a Internet (para descargas)
✓ Permisos de Administrador
✓ Mínimo 4GB RAM
✓ 2GB de espacio en disco


📁 PASO 1: COPIAR ARCHIVOS
================================================================================
1. En la computadora ACTUAL:
   - Copiar toda la carpeta: C:\INVE\inventario-app
   - Guardarla en una USB o compartir por red

2. En la computadora NUEVA:
   - Crear la carpeta: C:\INVE
   - Pegar la carpeta "inventario-app" dentro
   - Ruta final: C:\INVE\inventario-app

⚠️ NO COPIAR la carpeta "node_modules" (se reinstalará después)


💾 PASO 2: INSTALAR SQL SERVER
================================================================================
1. Descargar SQL Server 2019 Express:
   https://www.microsoft.com/es-es/sql-server/sql-server-downloads

2. Durante la instalación:
   ✓ Seleccionar "Instalación Básica"
   ✓ Aceptar términos de licencia
   ✓ Elegir ubicación de instalación
   ✓ Esperar a que termine (5-10 minutos)

3. Descargar SQL Server Management Studio (SSMS):
   https://aka.ms/ssmsfullsetup

4. Instalar SSMS (herramienta gráfica para administrar bases de datos)


🔧 PASO 3: CONFIGURAR SQL SERVER
================================================================================
1. Abrir "SQL Server Configuration Manager"
   (Buscar en el menú de Windows)

2. Habilitar TCP/IP:
   - Ir a: SQL Server Network Configuration → Protocols for MSSQLSERVER
   - Click derecho en "TCP/IP" → Habilitar
   - Click derecho en "TCP/IP" → Properties → IP Addresses
   - En "IPAll" configurar: TCP Port = 1433
   - Click OK

3. Habilitar Autenticación Mixta:
   - Abrir SQL Server Management Studio
   - Conectarse con Windows Authentication
   - Click derecho en el servidor → Properties → Security
   - Seleccionar: "SQL Server and Windows Authentication mode"
   - Click OK

4. Reiniciar SQL Server:
   - Abrir "Services" (Servicios de Windows)
   - Buscar "SQL Server (MSSQLSERVER)"
   - Click derecho → Reiniciar


🗄️ PASO 4: CREAR BASE DE DATOS Y USUARIO
================================================================================
1. Abrir PowerShell como Administrador
   (Click derecho en el menú Windows → Windows PowerShell (Admin))

2. Navegar a la carpeta de la aplicación:
   cd C:\INVE\inventario-app

3. Crear la base de datos:
   sqlcmd -S localhost -E -Q "CREATE DATABASE inventario_app"

4. Crear el usuario SQL:
   sqlcmd -S localhost -E -Q "CREATE LOGIN inventario_user WITH PASSWORD = 'Inv3nt4r10.2024'"

5. Asignar permisos:
   sqlcmd -S localhost -d inventario_app -E -Q "CREATE USER inventario_user FOR LOGIN inventario_user; ALTER ROLE db_owner ADD MEMBER inventario_user"

6. Crear las tablas:
   sqlcmd -S localhost -d inventario_app -E -i crear-tabla-conteo.sql

7. Verificar que las tablas se crearon:
   sqlcmd -S localhost -d inventario_app -E -Q "SELECT TABLE_NAME FROM INFORMATION_SCHEMA.TABLES"

   Debe mostrar:
   - REGISTROS_CONTEO_FISICO
   - SESIONES_CONTEO_FISICO


📦 PASO 5: INSTALAR NODE.JS
================================================================================
1. Descargar Node.js LTS (versión recomendada):
   https://nodejs.org/

2. Ejecutar el instalador:
   ✓ Aceptar términos
   ✓ Dejar todas las opciones por defecto
   ✓ Marcar "Automatically install necessary tools"
   ✓ Click Next → Install

3. Reiniciar la computadora (importante)

4. Verificar instalación (abrir PowerShell):
   node --version
   npm --version

   Debe mostrar números de versión (ej: v20.x.x y 10.x.x)


🔌 PASO 6: INSTALAR DEPENDENCIAS DE LA APLICACIÓN
================================================================================
1. Abrir PowerShell en la carpeta del proyecto:
   cd C:\INVE\inventario-app

2. Instalar paquetes de Node.js:
   npm install

   Esperar 2-3 minutos mientras descarga todo

3. Verificar que se creó la carpeta "node_modules"


🚀 PASO 7: INICIAR LA APLICACIÓN
================================================================================
1. Abrir PowerShell en la carpeta del proyecto:
   cd C:\INVE\inventario-app

2. Iniciar el servidor:
   npm start

3. Debe mostrar:
   =================================
   Servidor iniciado en puerto 3000
   =================================
   ✓ Conectado a SQL Server REMOTO
   ✓ Conectado a SQL Server LOCAL
   ✓ Listo para procesar solicitudes

4. Abrir el navegador y acceder a:
   http://localhost:3000/1-login.html

5. Probar el flujo completo:
   - Login → Seleccionar cuenta → Escanear ubicación → 
   - Escanear SKU → Capturar datos → Guardar


📝 PASO 8: VERIFICAR DATOS GUARDADOS
================================================================================
1. En PowerShell (mantener el servidor corriendo en otra ventana):
   sqlcmd -S localhost -d inventario_app -E -Q "SELECT COUNT(*) FROM REGISTROS_CONTEO_FISICO"

2. Debe mostrar el número de registros guardados

🆘 SOLUCIÓN DE PROBLEMAS COMUNES
================================================================================

❌ Error: "Cannot connect to database"
   Solución:
   - Verificar que SQL Server esté corriendo (Services → MSSQLSERVER)
   - Verificar TCP/IP habilitado en puerto 1433
   - Reiniciar SQL Server

❌ Error: "Login failed for user 'inventario_user'"
   Solución:
   - Recrear el usuario SQL (Paso 4, comandos 4-5)
   - Verificar que la contraseña sea: Inv3nt4r10.2024

❌ Error: "npm: command not found"
   Solución:
   - Reinstalar Node.js
   - Reiniciar la computadora
   - Verificar que Node.js esté en el PATH

❌ Error: "ERR_CONNECTION_REFUSED"
   Solución:
   - El servidor no está corriendo
   - Ejecutar: npm start

❌ Error: "Puerto 3000 en uso"
   Solución:
   - Cerrar procesos node anteriores:
     Get-Process node | Stop-Process -Force
   - Volver a ejecutar: npm start
