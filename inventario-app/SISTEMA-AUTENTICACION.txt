FLUJO DE LA APLICACIÓN:
===============================================

1. LOGIN (1-login.html)
   - Ingresar usuario y contraseña
   - El sistema valida contra la base de datos
   - Si las credenciales son correctas, redirige a selección de cuenta
   - Si son incorrectas, muestra mensaje de error

2. SELECCIÓN DE CUENTA (2-seleccion-cuenta.html)
   - Muestra bienvenida con nombre y rol del usuario
   - Usuario selecciona bodega y cuenta
   - Solo administradores ven el botón "📊 Ver Reportes"
   - Botón "Cerrar Sesión" limpia la sesión y regresa al login

3. PROCESO DE CONTEO (3, 4, 5 y B archivos HTML)
   - Funciona igual que antes
   - El usuario ya está autenticado en este punto

4. REPORTES (6-reportes.html)
   - SOLO ACCESIBLE PARA ADMINISTRADORES
   - Si un operador intenta acceder, es redirigido
   - Permite descargar reportes por cuenta y periodo de fechas

===============================================
BASE DE DATOS:
===============================================

Tabla: USUARIOS
Campos:
- id_usuario (INT, PK, IDENTITY)
- nombre_usuario (VARCHAR(50), UNIQUE)
- password_hash (VARCHAR(255))
- nombre_completo (VARCHAR(100))
- rol (VARCHAR(20)) - 'Administrador' o 'Operador'
- activo (BIT) - 1 = activo, 0 = inactivo
- fecha_creacion (DATETIME)
- fecha_ultimo_acceso (DATETIME)

===============================================
AGREGAR NUEVOS USUARIOS:
===============================================

Para agregar más usuarios, ejecutar en SQL Server:

INSERT INTO USUARIOS (nombre_usuario, password_hash, nombre_completo, rol)
VALUES ('nombre_usuario', 'contraseña', 'Nombre Completo', 'Administrador');
-- o 'Operador' según el rol deseado

Ejemplo:
INSERT INTO USUARIOS (nombre_usuario, password_hash, nombre_completo, rol)
VALUES ('juan', 'pass123', 'Juan Pérez', 'Operador');

===============================================
DESACTIVAR UN USUARIO:
===============================================

UPDATE USUARIOS 
SET activo = 0 
WHERE nombre_usuario = 'nombre_usuario';

===============================================
CAMBIAR CONTRASEÑA:
===============================================

UPDATE USUARIOS 
SET password_hash = 'nueva_contraseña' 
WHERE nombre_usuario = 'nombre_usuario';
